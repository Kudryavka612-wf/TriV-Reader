# TriV-Reader

PySide6 + PyMuPDF 製の自作 PDF ビューワー / エディタ（Windows）。

閲覧・連続スクロール・回転・注釈（ハイライト/ペン/図形/テキスト/付箋/下線/取消線/墨消し）・
ページ操作（分割/統合/抽出/削除/並べ替え/白紙挿入/複製/トリミング）・しおり・検索・
ページ番号・透かし・ヘッダー/フッター・OCR・画像変換・圧縮・パスワード保護・タブ表示・
ダーク/ライト・ポータブル対応・自動更新 などに対応。

- 設定ダイアログ（`Ctrl+,` / リボンの「設定」）に全般・表示・注釈・保存・更新・
  詳細をまとめてあります。起動時の復元、注釈の既定スタイルと作成者名、保存時の
  バックアップ、自動保存などもここから。
- 見た目は配色トークン 1 か所（`viewer/theme.py`）で管理しています。ライト/
  ダークともリボン・タブ・メニュー・入力欄まで一括で切り替わり、ダークでは
  Windows のタイトルバーも黒くなります。ページには落ち影が付き、余白の色と
  「紙」の色もテーマ連動です。
- 起動直後の画面には最近使ったファイルが並び、1 クリックで開き直せます。
- 圧縮（リボンの「保護」→ 圧縮、または ファイル メニュー）は埋め込み画像を
  指定した解像度まで縮小して入れ直します。スキャン PDF が数分の一になります。
  文字や図形はそのまま残るので、検索・コピー・注釈・しおりは保たれます。
  高画質(200dpi) / 標準(150dpi) / 最小(96dpi) / 無劣化 から選べ、「試算」で
  圧縮後のサイズを確認してから保存できます。画像が既に小さい PDF では
  何もせず元のサイズのままにします（太らせない）。
- 印刷はベクター出力が既定です。プリンタの解像度でそのまま出るので文字がくっきり
  します（図版が崩れる PDF 向けに画像化 300/600dpi も選べます）。
- マウスジェスチャー: ページの上で右ボタンを押しながら
  ↓ タブを閉じる / ← 前のタブ / → 次のタブ / ↑ 先頭ページ。
  割り当ては設定から変えられます。
- 中ボタンを押すとオートスクロール（上下左右）。もう一度押すと止まります。
- 文字選択はページをまたいでドラッグでき、`Ctrl+A` で文書全体を選べます。
  ダブルクリックで語、トリプルクリックで行。右クリックからコピー・ハイライト・
  下線・取消線・選択文字列で検索ができます。

## 速度について
- ページの描画結果はメモリにキャッシュ（既定 128MB・古い順に破棄）します。
  一度見たページへ戻るときは描き直しません。スクロールが止まると前後の
  ページを先読みします。
- 入力欄が数百ある官公庁フォームは、欄の生成と未対応機能の走査を最初の
  描画のあとに回しています（開いた瞬間に固まらない）。
- 中身を変えたときは必ずキャッシュを捨てるので、古い絵が残ることはありません
  （`render_cache_test.py` で検証）。

## 実行（ソースから）
```powershell
pip install -r requirements.txt
python main.py
```

## ビルド / 配布 / 自動更新
[BUILD.md](BUILD.md) を参照。

- 通常ビルド: `python build_exe.py`
- 軽量版（OCRなし）: `python build_exe.py --lite`
- ポータブル版: `python build_exe.py --portable`
- 1コマンド公開（要 GitHub CLI）: `python release.py --notes "更新内容"`

## 自動リリース（GitHub Actions）
`viewer/version.py` の `APP_VERSION` を上げてコミットし、`vX.Y.Z` タグを push すると
クラウドで自動ビルドされ、GitHub Releases に公開されます（`.github/workflows/release.yml`）。
